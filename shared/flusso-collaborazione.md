# Flusso di Collaborazione

## Principio

Questo modulo ribadisce il criterio generale di collaborazione tra utente e agente.

## Regola

Le regole operative vincolanti su checklist, step, item, conferme, stop operativi e uso delle skill sono definite nel modulo [Workflow Operativo](./workflow-operativo.md).

Ordine di precedenza obbligatorio:

1. `workflow-operativo.md` per aspetti operativi;
2. altri file `shared/*.md` per le regole condivise non operative;
3. `AGENTS.md` per istruzioni sulla struttura del progetto che non contraddicono i moduli condivisi.
